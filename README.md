# REPS

A polished frontend-only workout tracking prototype built with Next.js 15, TypeScript, Tailwind CSS, and shadcn/ui-style components.

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Pages

- `/` landing page
- `/dashboard` dashboard with dummy training metrics
- `/workout` local-state workout set tracker
- `/exercises` searchable dummy exercise library

No authentication, backend, database, Supabase, or deployment is included.
